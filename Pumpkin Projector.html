Timed lyrics

The feed makes the dancing follow the beat, lets the mouths follow the real loudness a little, and lets Wait for sound start the lyrics. Set it up in the box that appears below.

Paste lyrics you have the right to use, one line per row, with a time before each line like [0:12.50]. This page does not include or look up lyrics. Then set a pumpkin's source to Timed lyrics.

Wait for sound starts the lyrics by itself the moment the first sound is heard from the shared MP3, tab audio or microphone, using your start point as the time. Raise Sound level if room noise starts it too early, or lower it if it starts too late.

Play the song yourself, in Spotify or anywhere else. When it reaches your start point, press Start lyrics. If the mouths run early or late, use the nudge buttons. Line spacing is only used when the lyrics have no times, and Syllable sets how long each syllable lasts. Spotify does not let other pages read its audio or play position, so this keeps time with its own clock.
